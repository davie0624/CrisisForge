# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting

Do not place credentials, private datasets, account details, or exploitable
security reports in a public issue. Use GitHub's private vulnerability-reporting
feature when it is available for this repository.

Ordinary reproducibility problems, numerical bugs, and documentation errors may be
reported through a public GitHub issue, provided that the report contains no
sensitive information.

## Research-use boundary

CrisisForge is research software, not investment advice, a live trading system, or
a production risk-control service. Generated scenarios and portfolio outputs require
independent validation before any real-world use.
